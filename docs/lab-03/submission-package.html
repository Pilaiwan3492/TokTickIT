My Reflection on AI Use

Using an AI coding agent throughout Lab 3 delivered remarkable engineering acceleration while keeping architectural integrity intact. Because we invested significant effort in upfront contract specification (Spec DD), the AI agent operated within strict boundaries, preventing regression of completed Lab 1 and Lab 2 capabilities.

However, human engineering judgment remained indispensable for security boundaries and edge cases. In Issue 27, while the agent implemented demotion guards, human review identified that deactivating the last active administrator was an equally dangerous vulnerability, prompting the addition of database transaction locks and race condition test API-45b. Similarly, human oversight was vital in ensuring touch targets met ≥ 44px without breaking native toggle switch semantics. AI serves as a powerful multiplier, but human vigilance ensures software remains production-grade and secure.
