My Reflection on AI Use

Developing TokTickIT Lab 4 with an AI coding partner demonstrated the great power of Specification-Driven Development (Spec DD). When rigorous constraints and state machine matrices were provided upfront, the AI agent executed complex full-stack features with remarkable velocity, maintaining 100% test coverage across 547 tests without legacy regressions.

Crucially, human engineering oversight remained irreplaceable in concurrency modeling and authentic accessibility. In optimistic concurrency, human analysis ensured that adding an Action Taken checked the parent ticket's updatedAt timestamp, preventing race conditions where work was logged against concurrently closed tickets. Similarly, peer review challenged synthetic .focus() calls in keyboard tests, directing the transition to real sequential Tab traversal. AI empowers rapid execution, but human engineers remain the essential architects of system reliability.
